## 🚀 VMオプション  

| key                          | value                    | 必須        | 説明                                                                                                 |
| ---------------------------- | ---------------------- | ----------  | ---------------------------------------------------------------------------------------------------- |
| -Dinstance                   | コマンドラインマーカー     | ✅        | 重複起動を抑止するためマーカーを指定する（ビルド時に生成されたUUID）                                             |
| -Dagentjar                   | エージェントファイルパス   | ✅        | エージェントJarファイルの配置先を指定する。重複起動、初期化プロセスで使用                                          |
| -Dapp.io.tmpdir              | 一時フォルダパス          | ✅        | 一時フォルダをクリーンアップする際、デフォルトのフォルダを誤ってクリーンアップしない工夫                              |
| -Dapp.io.archivedatadir      | アーカイブフォルダパス     | ✅        | 仮想ファイルシステムとして使用するファイル保管パス。アプリケーション実行時に自動的にメタデータをクリーンアップする        |
| -Dapp.logs.dir               | ログフォルダパス          |           | アプリケーションロガーのログファイル格納先                                                                    |
| -Dapp.class.pool.size        | DIロード時プールサイズ     | ✅        | エージェントによってBeanを生成するが、その時にトランスフォーマー外で一度FQCNをプールするサイズの上限値                 |
| -LoardDIBeans.Adapter        | DIロードプロセッサー名     |           | DIコンテキストを生成・構築するエージェント向けプロバイダー(SPI)                                                 |

## 🛠️ その他共通オプション 
| key                          | value                    | 必須        | 説明                                                                                                 |
| ---------------------------- | ---------------------- | ----------  | ---------------------------------------------------------------------------------------------------- |
| -XX:VMOptionsFile            | ファイルパス              | ✅        | 任意のVMオプションを指定することを可能にするための工夫。VMオプションを書き込むためのファイルを指定する                 |
| -XX:CompileCommandFile       | ファイルパス             | ✅        | JITコンパイラ向けのオプションを記載したファイルを指定する。ATPによってコンパイル時にファイルは自動生成される            |
| -javaagent                   | Javaエージェントjarパス   |           | Javaエージェントのエントリポイントを内包したjarファイルを指定する。主にKagerowの初期化処理をするため。                |
| -client                      | -                       |           | GUIの軌道をできる限り速くするため、クラスロードを必要最低限にするための工夫。                                      |
| -XX:+UseG1GC                 | -                       |           | GCを開発環境と実行環境で安定させるために指定。主に強参照ではないインスタンスの挙動に影響する                          |
| -XX:+CrashOnOutOfMemoryError | -                       |           | JVMがクラッシュした際レポートを出力する                                                                      |
| -XX:+PrintGCDetails          | -                       |           | 必要最低限のJVMログを出力する。主に不具合解析に使用する。                                                       |

## ☕️ その他個別オプション 
| key                          | value                  | プラットフォーム        | 説明                                                                                         |   
| ---------------------------- | ---------------------- | -------------------- | ------------------------------------------------------------------------------------------- |
| -Xdock:name                  | Kagerow                | Mac                  | dockに表示しする際のアプリケーション名称を指定している                                               |
| -Xdock:icon                  | アイコンファイルパス      | Mac                   | dockに表示する際のアプリケーションアイコンを指定している                                             |

## 🔧 ディレクトリ構成  
```shell
% tree -a -I ".git|.vscode|.DS_Store|target|.classpath|.project|.settings|*.properties" -L 1
.
├── cache       # キャッシュファイルを保持するディレクトリ
├── database    # 論理DBファイルを保持するディレクトリ
├── logs        # ログファイルを保持するディレクトリ
├── plugin      # プラグインパッケージを保持するディレクトリ
├── runtime     # 動作環境にて動的に出力されるディレクトリ
└── tmp         # 動作環境にて動的に出力される一時ディレクトリ
```
